# ApplyPilot AI — Master Product Requirements Document (PRD)

**Version:** 1.0  
**Status:** Approved Blueprint  
**Target Workspace:** `ApplyPilot-AI/`

---

## 1. Product Vision & Objective

**ApplyPilot AI** is a personal, continuously running AI job-acquisition and career-operations system—not merely a resume generator. It is engineered to maximize interview callbacks for **Software Development Engineer (SDE)**, **Software Engineer (SWE)**, **AI Engineer**, **Applied AI Engineer**, **Junior AI/ML Engineer**, and relevant **Backend Engineer** roles by:

1. **Discovering** high-fit, fresh openings before they go stale across India and remote worldwide.
2. **Tailoring & Validating** strictly truthful, job-specific resumes (**PDF-only tailored output**; PDF + DOCX master resume ingestion) grounded in verified candidate evidence, starting in `pending_review` for explicit owner approval.
3. **Submitting & Tracking** applications under an explicit permission policy with verification and zero duplicate submissions.
4. **Preparing** the candidate for interviews generated by confirmed applications through role- and company-specific Interview Kits and adaptive mock interviews.

Success is measured by **relevant interview callbacks and job offers**, not raw resume count or blind application volume.

## 3. Core Product Principles

1. **Truthfulness:** Never fabricate skills, work experience, certifications, project features, dates, metrics, or qualifications. Every resume claim and application answer must trace to verified Master Profile evidence.
2. **Relevance Over Volume:** If only 5 suitable openings exist on a given day, report 5 rather than lowering eligibility thresholds or auto-submitting weak matches to hit 10–15.
3. **Candidate Control:** Enforce explicit LangGraph `interrupt` human approval whenever an application uses browser-assisted or manual submission rather than an authorized official API.
4. **Reliability & Idempotency:** Persist workflow checkpoints, enforce unique application keys, and independently verify submission outcomes before marking an application `CONFIRMED`.
5. **Privacy & Security:** Minimize PII sent to external LLMs, isolate browser contexts, never expose credentials/cookies to LLMs or frontend bundles, and treat all external JDs/web pages as untrusted data.
6. **Full Traceability:** Preserve the original JD, tailored DOCX/PDF versions, match report, application answers, approval decision, and submission proof for every application.

## 4. End-to-End 12-Step Workflow

1. **Master Profile & Resume Vault:** Ingest the Master Resume and maintain a structured, verified candidate profile (education, skills with evidence, projects distinguishing implemented vs. planned features, internships, certifications, achievements, links, and confirmed preferences).
2. **Job Discovery:** Concurrently query permitted job boards (Greenhouse Job Board API, Lever Postings API), approved career pages, and permitted search integrations.
3. **Normalization & Deduplication:** Normalize jobs into `NormalizedJob`, keep `posted_at` distinct from `discovered_at`, deduplicate across sources, and verify active posting status.
4. **Structured JD Intelligence:** Parse JDs into `JobRequirements`, classifying mandatory, preferred, and trainable skills plus hard eligibility restrictions and ambiguous requirements.
5. **Eligibility & Transparent Match Scoring:** Enforce hard eligibility gates first, then compute a transparent 100-point weighted score (Skills 40, Project Relevance 20, Experience 15, Education 10, Location/Work Mode 5, Freshness 5, Role Alignment 5).
6. **Resume Tailoring:** Reorder verified skills, prioritize relevant projects, rewrite role-aligned summaries and evidence-backed bullets, and generate ATS-friendly **PDF-only** artifacts (`AUTO_TAILOR_ENABLED`, `AUTO_TAILOR_DAILY_LIMIT`, `AUTO_TAILOR_MIN_SCORE`), starting every version in `pending_review`.
7. **ATS & Factual Validation Gate:** Run deterministic text extraction, parsing checks, keyword coverage analysis, and fact-consistency verification against the Master Profile (never rely on an LLM score alone).
8. **Application Preparation:** Map verified candidate facts to form schemas, classify unknown/sensitive questions (legal eligibility, sponsorship, salary), and pause for user input if any answer is unverified.
9. **Policy-Routed Submission:** Auto-submit only via authorized official APIs within daily caps; otherwise pause at a LangGraph approval checkpoint for explicit user decision. Never bypass CAPTCHAs, MFA, or site terms.
10. **Submission Verification:** Independently confirm via API response ID, success page confirmation, or confirmation email before promoting `SUBMITTED` to `CONFIRMED`.
11. **Tracking & Gmail Notification:** Update the persistent Application Tracker and send an accurate OAuth2 Gmail notification (distinguishing `confirmed`, `needs_user_input`, `unverified`, and `failed`).
12. **Interview Preparation & Memory:** Generate a tailored Interview Kit (company research, fundamentals, DSA, role-specific, resume deep dive, system design, STAR behavioral, adaptive mock interview) tied to the exact submitted resume and JD, backed by cross-application Interview Memory.

## 5. Product Success Metrics

- **Relevant Jobs Discovered:** Count of unique, active openings passing eligibility and minimum match thresholds (`MIN_JOB_MATCH_SCORE`, default `75`).
- **Quality Applications:** Applications passing both match thresholds and factual validation gates.
- **Application Completion Rate:** Prepared applications reaching `CONFIRMED` status.
- **Duplicate Prevention Rate:** Duplicate submissions successfully blocked by idempotency keys.
- **Resume Factuality:** Percentage of generated resume claims traceable to verified Master Profile evidence (target: **100%**).
- **Interview Callback Rate & Readiness:** Callbacks per confirmed application and mock-interview readiness progress (clearly labelled as estimates).
- **Cost & Time Saved:** Token/API cost per workflow and candidate hours saved.
