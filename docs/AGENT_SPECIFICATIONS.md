# ApplyPilot AI — Agent Specifications

> **Design Rule:** Agents represent logical responsibilities, not 20 isolated LLM calls. Deterministic tasks (deduplication, eligibility rules, scoring math, PDF/DOCX parsing, fact cross-checks, idempotency, state transitions) run as deterministic Python services.

---

## Group 1: Discovery Intelligence

| Agent / Service             | Mode                                         | Inputs                                     | Outputs                                        | Core Responsibilities & Guardrails                                                                                                                                                                                                |
| --------------------------- | -------------------------------------------- | ------------------------------------------ | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Job Hunter Agent**        | Hybrid (Rules + Gemini)                      | `SearchPreferences`, enabled `job_sources` | Search queries & connector dispatch plan       | Translates target roles (`SDE`, `SWE`, `AI Engineer`, `Applied AI`, `Junior AI/ML`, `Backend`), geography (`India + Remote`), and experience (`0–2 yrs / Intern / Fresher`) into source queries.                                  |
| **Job Source Connector**    | Deterministic async Python                   | Query, location, filters, connector config | Raw & `NormalizedJob` records                  | Implements `JobSourceConnector` (`search`, `fetch_job`, `normalize`, `check_status`) for Greenhouse Job Board API, Lever Postings API, permitted search APIs, and approved career pages. **Never scrapes or automates LinkedIn.** |
| **Job Deduplication Agent** | Deterministic Python (+ pgvector similarity) | `NormalizedJob` batch, existing `jobs`     | Deduplicated active jobs                       | Matches canonical URLs, `(source, source_job_id)`, and normalized `(company, title, location)` similarity; preserves `posted_at` distinct from `discovered_at`.                                                                   |
| **JD Analyzer Agent**       | Gemini + Pydantic validation                 | Raw JD text, URL                           | `JobRequirements`                              | Treats JD text strictly as untrusted data. Extracts mandatory vs. preferred vs. trainable skills, experience bounds, education, location/remote policy, and `uncertainties`.                                                      |
| **Eligibility Agent**       | Deterministic Python                         | `JobRequirements`, `CandidateProfile`      | `EligibilityResult` + weighted score (`0–100`) | Applies hard eligibility gates first (e.g., `3+ yrs` required -> ineligible regardless of skill overlap), then computes transparent 100-pt score (`40+20+15+10+5+5+5`).                                                           |

## Group 2: Resume Intelligence

| Agent / Service                                       | Mode                                                      | Inputs                                                                      | Outputs                                              | Core Responsibilities & Guardrails                                                                                                                                                                                                                                                   |
| ----------------------------------------------------- | --------------------------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Resume Analyzer Agent** (`ResumeAnalyzerAgent`)     | Deterministic Python                                      | Uploaded master PDF/DOCX + `CandidateProfile`                               | `MasterResumeAnalysis`                               | Extracts baseline sections, bullets, word count, and public links; falls back cleanly to verified `CandidateProfile` records if no master file exists.                                                                                                                               |
| **Evidence Retriever** (`EvidenceRetriever`)          | Deterministic + `pgvector`                                | `CandidateProfile`, `Job`, `JobRequirement`, master `Resume`                | `RetrievedCandidateEvidence` + SHA-256 fingerprint   | Retrieves verified entity-scoped evidence with content-derived education/achievement IDs; excludes unverified skills and `planned_features`.                                                                                                                                         |
| **Resume Tailoring Agent** (`ResumeTailoringAgent`)   | Claude-first + Deterministic fallback                     | `RetrievedCandidateEvidence`, `Job`, `JobRequirement`                       | `TailoredResumeContent` + `TailoringDiff`            | Wraps JD text in `<UNTRUSTED_JD_DATA_*>` delimiters, reorders verified skills/projects, rewrites grounded bullets, and falls back deterministically when LLM providers are unavailable.                                                                                              |
| **ATS Optimization Agent** (`ATSOptimizationAgent`)   | Deterministic Python                                      | `TailoredResumeContent`, `JobRequirement`, rendered PDF bytes               | `ATSOptimizationReport`                              | Checks JD keyword coverage, standard ATS headings, bullet conciseness/action verbs, and round-trip PyMuPDF text extractability.                                                                                                                                                      |
| **Factual Validator Agent** (`FactualValidatorAgent`) | Authoritative Deterministic + optional OpenAI cross-check | `TailoredResumeContent` vs. `RetrievedCandidateEvidence`                    | `FactualValidationReport` (per-claim classification) | Classifies every claim (`supported_fact`, `rewritten_fact`, `unsupported_claim`) with zero silent passes. Blocks fabricated skills/metrics, cross-project tech leakage, promoted `planned_features`, and altered dates/GPAs/certs. Optional LLM cross-check can only add rejections. |
| **Resume Evaluator Agent** (`ResumeEvaluatorAgent`)   | Deterministic/Heuristic                                   | `TailoredResumeContent`, `ATSOptimizationReport`, `FactualValidationReport` | `ResumeEvaluationReport` (7 metrics + disclaimer)    | Computes `required_skill_coverage`, `preferred_skill_coverage`, `relevant_evidence_coverage`, `keyword_coverage`, `factual_consistency_score`, `readability_score`, and `pdf_parsing_quality_score`.                                                                                 |

## Group 3: Application Operations

| Agent / Service                    | Mode                               | Inputs                                        | Outputs                               | Core Responsibilities & Guardrails                                                                                                                                                                    |
| ---------------------------------- | ---------------------------------- | --------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Application Agent**              | Deterministic Router + API/Browser | Validated resume, `ApplicationSchema`, policy | Submission request / `interrupt()`    | Enforces submission policy: auto-submit **only** on authorized official APIs within daily caps; triggers LangGraph `interrupt()` approval for browser/manual flows; blocks duplicates & expired jobs. |
| **Form Understanding Agent**       | Hybrid (Schema + LLM)              | Application form fields, `MasterProfile`      | Mapped answers + `unknown_questions`  | Maps verified candidate fields; classifies unknown/sensitive questions (work auth, sponsorship, salary, legal declarations) and pauses for `NEEDS_USER_INPUT` instead of guessing.                    |
| **Application Verification Agent** | Deterministic Python               | API response / Playwright DOM / confirmation  | `SubmissionVerification`              | Never treats a click as proof. Requires confirmation ID, verified confirmation screen, or email receipt before transitioning `SUBMITTED` → `CONFIRMED`.                                               |
| **Email Notification Agent**       | Deterministic Python + Gmail API   | Application record, verification status       | OAuth2 email (`sent_at`, status)      | Sends distinct notifications (`confirmed`, `needs_user_input`, `unverified`, `failed`, daily digest). Never sends a success email for unverified or merely prepared applications.                     |
| **Application Tracker Agent**      | Deterministic Python               | Lifecycle events                              | Updated `applications` & `audit_logs` | Enforces state-machine transitions (`DISCOVERED` → `CONFIRMED` → `INTERVIEW`/`REJECTED`/`WITHDRAWN`), schedules follow-ups, and writes immutable audit trails.                                        |

## Group 4: Career Intelligence

| Agent / Service              | Mode                        | Inputs                                     | Outputs                         | Core Responsibilities & Guardrails                                                                                                                                     |
| ---------------------------- | --------------------------- | ------------------------------------------ | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Company Research Agent**   | Gemini + Web/Public Sources | Company name, JD                           | Company brief                   | Summarizes products, business model, public engineering stack, and clearly separates verified facts from general expectations.                                         |
| **Interview Question Agent** | Claude / OpenAI             | JD, exact submitted resume, company brief  | Categorized questions           | Generates technical fundamentals, DSA, role-specific, resume deep-dive (strictly grounded in submitted resume), system design, and STAR behavioral prompts.            |
| **Technical Solution Agent** | Claude / OpenAI             | Question set                               | Solutions + complexity analysis | Produces conceptual explanations, Python/Java code implementations, time/space complexity, and trade-off discussions (never claims to know exact interviewer prompts). |
| **Mock Interview Agent**     | OpenAI                      | `InterviewKit`, `InterviewAttempt` history | Adaptive Q&A + rubric feedback  | Runs interactive mock sessions, updates **Interview Memory** (weak topics, recurring cross-JD skills like LangGraph), and tracks estimated readiness.                  |
| **Follow-up Agent**          | Deterministic Scheduler     | `applications` timestamps                  | Follow-up reminders & drafts    | Tracks post-application follow-up dates and surfaces reminders in dashboard/notifications (requiring explicit approval before sending external emails).                |

---

## Supervisor Agent (`backend/app/agents/supervisor/`)

Coordinates the Master LangGraph state (`ApplyPilotState`), enforces global pause/emergency-stop flags, bounds retries with exponential backoff, respects daily caps (`MAX_APPLICATIONS_PER_DAY`), and emits real-time `workflow_update` events.
